ℹ️ 关于项目

                

                    
这是一个从零开始构建的toy级别LLM推理引擎，用于学习和理解Transformer模型的底层实现。

                    
技术栈

                    
    
                        
  • C++17 - 核心实现语言
    • 
                        
  • WebAssembly - 浏览器端运行
    • 
                        
  • Emscripten - C++到WASM编译工具
    • 
                    

                    
已实现功能

                    
    
                        
  • ✅ 基础矩阵运算（加法、乘法、转置）
    • 
                        
  • ✅ Linear层（全连接层）
    • 
                        
  • ✅ LayerNorm（层归一化）
    • 
                        
  • ✅ Self-Attention（自注意力机制）
    • 
                        
  • ✅ FeedForward Network（前馈网络）
